    只改契约与连线，不写代码 · 写砸了可撤销
    三条规矩先记住：方块 = 文件夹 + 契约；连线 = 需求被提供满足；出口只有指令包。
    01一个方块 = 一个文件夹 + 一份 spec.md

    方块左边是「提供」，右边是「需要」，中间（模块页里）是「约束」。这三段就是它的全部契约，不写实现细节。

    02连线 = A 的某条「需要」由 B 的某条「提供」满足

    从「需要」右边的圆点拖到对方的「提供」条目上。一条需求恰好由一条提供满足；删掉线，需求就变成红色缺口。

    03双击方块 = 进入模块页

    在模块页里加、改、删这个模块自己的三段条目。空白处双击 = 新建模块；拖方块 = 摆位置；Shift + 拖空白 = 框选。

    04顶栏「问题 N」= 校验器的输出

    缺口、歧义、越界都在这里，点一条就跳到对应节点。方块左上角出现红三角，说明它有错误。

    05出口只有一个：导出指令包

    导出的只有契约，没有代码。把它交给 AI 或同事去实现，实现结果再回来补契约。

    想看完整的？点「模块库 → 放入用户中心示例」。
    不清楚「需求必须闭合」是什么意思？把示例拖出来，删掉一条线，看它变成红色。
