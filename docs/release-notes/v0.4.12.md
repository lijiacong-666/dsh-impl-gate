# 0.4.12 — 把 specgraph 前置依赖写清楚

## 改了什么

- README 安装段加一句前置说明：`materialize` / `check` 需要 `python -m specgraph`，没装时返回 `PYTHON_ENV_MISSING`，不会假装成功。
- 新增 [`docs/install-specgraph.md`](install-specgraph.md)：Python 版本、拿到 specgraph、三种指定路径的方式（参数 / 配置 / 自动上溯）、四种常见报错、以及「为什么不做成内置」。
- `scripts/check-package.mjs` 把这份文档列进必含文件，避免发版时漏掉。

## 为什么

插件发到 npm，但契约图校验器是独立的 specgraph；外部用户装完插件直接物化会撞 `PYTHON_ENV_MISSING`，而 README 之前只在一行里提过 `python -m specgraph`，没给安装路径。这是发行版的真实缺口，不是文档美化。

## 升级注意

无代码行为变化，只影响文档与包内容。
