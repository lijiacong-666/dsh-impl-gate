# v0.3.9

## 改动

- `materialize` 不再拒绝「目录里有不是它生成的文件」。实现阶段代码本来就会堆在那里，之前改一次 plan 就得先挪走代码。
- 现在只拒绝一种情况：**即将写入的文件已存在、且不在 `ownership.json` 里**（例如手写的 `demo-app/shared/spec.md`）——避免覆盖人类产物；其余文件一律不动。
- 冲突检查提前到 python preflight 之前，坏解释器不会再盖住真正的冲突原因。

## 升级注意

- 错误文案从 `target contains files not written by impl-gate` 改为 `refusing to overwrite files impl-gate does not own`。

## 已知缺口

- 同 0.3.6。
