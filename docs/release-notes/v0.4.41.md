# 0.4.41 — 报告多一段可直接贴进 PR 的 Markdown

## 为什么

`impl_gate_report` 的输出原来只服务眼睛：一行汇总、覆盖声明、若干理由。要贴到 PR 评论里得手工重排，而且每个人排得不一样——同一份 run 在不同 PR 里长得不同，没法对比。

## 改了什么

`ReportPayload` 新增 `markdown`；`reportMarkdown()` 只产一张表，不写散文：

```markdown
### impl-gate report

| check | result |
| --- | --- |
| assertions | PASS 10 / FAIL 0 / NOT-RUN 22 |
| coverage | 未覆盖集合 ≡ NOT-RUN 集合（相等） |
| readiness | ready to hand over |
```

- 有 FAIL：多一行 `| failed | A2, M3 |`
- 不 ready：每条理由一行 `| reason | … |`，理由里的 `|` 转义成 `\|`，表格不散
- `renderReport` 在末尾加 `paste into a PR comment:` 再贴这段——输出是文本工具，不给出口等于没加

## 测试

`tests/report-markdown.test.mjs` 4 例：

1. 三行齐（assertions / coverage / readiness）+ failed + reason
2. 32 行全 PASS 时无 failed/reason 行，coverage 说「相等」
3. 理由里的 `|` 被转义
4. `coverageStatement` 只在 32 行对齐时说「相等」（31 行说「不等」）

全量 350 tests / 345 pass / 5 skip / 0 fail；`tsc --noEmit` 干净。

## 升级注意

`report` 的文本输出多了 Markdown 段。脚本若按行号解析旧输出，请改成读 `markdown` 字段或只读前两行。

## 已知缺口

`markdown` 与 `readiness` 是同一份数据的两种投影；理由多时表格会长，没做截断——宁可长，不丢信息。
