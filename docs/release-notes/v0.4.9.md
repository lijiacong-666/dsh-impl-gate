# 0.4.9

`impl_gate_compose` 直接给出「可以原样粘给评审者」的评审提示词。

## 变更

- `compose` 返回的 `review` 增加 `prompt`（一段现成文本），物化时原样打印：

  ```text
  review prompt (paste to the reviewer as-is):
    你是这份设计文档的独立评审者。只读 …/SPEC.md，不要读 compose-plan.json、tasks/ 或任何实现代码……
    对每一个模块给三态判定：可开工 / 需澄清 / 不可开工……
    证据一律写成 SPEC.md:<行号>……
    通过线是 blocked = 0 且 blocking = 0……
    把判定写回：调用 impl_gate_review，outDir = ……
  ```

- 提示词里带上了具体的 `SPEC.md` 绝对路径与 `outDir`，评审者不需要再被解释「哪份文件、写回哪里」。
- `tests/review-prompt.test.mjs` 4 例（路径、禁读 plan、三态、证据格式、通过线、写回方式、稳定性）。

## 为什么

评审提示词此前只存在于 `playbooks/review.md` 的散文里。调用方（人或其他 agent）每次都要自己拼一遍，常见漏项是「不要读 plan」和「证据要给行号」——这两条恰恰决定了评审能不能发现「文档没写、读者替它补全」的缺口。

## 兼容

`review` 多一个字段；严格校验键集的脚本需要放行 `prompt`。
