# 0.4.26 — 英文 README 补到与中文同构

## 改了什么

`README.en.md` 从 240 行补到 292 行，与中文版对齐了这些内容：

- 工具表补 `impl_gate_review`、`impl_gate_record` 两行，并把 `impl_gate_compose` 的 `plan` / `draft` / `materialize` 三种模式写清
- 新增 **Implementation evidence**、**Review records**、**What `impl_gate_compose` writes** 三节
- 新增 **Warnings** 一节：37 类按 A（契约没闭合）/ B（决定没做）/ C（可能误报）分组，链到 `docs/WARNINGS.md`
- 首屏加 FAQ、QUICKSTART 与三份案例的链接
- Development 段补 `pnpm verify:full`，并说明 `smoke:ci` 在裸机上是静默跳过

## 为什么

0.3.x 之后新增的六类能力（compose 双模式、review、record、证据/一致性、警告体系、案例）在英文 README 里全部缺席。英文用户读到的是「一个校验 32 条断言的工具」，与现在的能力差距太远——这比缺一段翻译更糟，属于误导。

## 实测

```
$ node scripts/check-package.mjs
Package ok: 72 files, 176662 bytes.
```

段落结构与中文版一致（What it is / Minimal example / Field test / Input formats / Tool parameters / Warnings / Error codes / Boundaries / Deviations / Manual review items / Update, roll back, remove / Privacy / Compatibility / Development / License）。

## 已知缺口

- 英文版仍比中文版少「实测：会议室预订」里的六轮评审表格细节，只保留了结论段——那张表是中文读者向的，翻译收益低。
- `docs/` 下的长文档（WARNINGS、QUICKSTART、FAQ、案例）只有中文；英文 README 以链接指向它们，并在 Warnings 节先给了三类分组的摘要。
