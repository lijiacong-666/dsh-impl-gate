# 0.4.2

两条「实现者只能自己猜」的机检：可选查询参数的默认值、验收断言读不到的响应字段。

## 变更

- `QUERY_DEFAULT_UNSTATED`：可选查询参数既没有 `note`，所属模块的约束与全局约定里也没有一句写它的缺省/上限时报警（`GET /api/runs → limit has no default stated`）。四份真实 plan 无误报——它们都写了 note 或约束。
- `AC_FIELD_UNKNOWN`：验收断言里 `body.x` 指向的字段，在其唯一可判定的响应类型上不存在时报警（`M3: a-1 reads body.secret but TokenPair has no such field`）。4xx 场景读统一错误体（`body.error/message/code/details`）不算。
- `tests/warnings.test.mjs` 增至 29 例；README 记到 29 类（README 的 27 类计数已同步修正）。

## 升级注意

`AC_FIELD_UNKNOWN` 只在「断言里只提到一条路由」时才判——一句话同时覆盖多条路由的验收行会被跳过，避免把 A 路由的状态码套到 B 路由的响应上。
