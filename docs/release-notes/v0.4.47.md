# v0.4.47 — 把「一句话」的边界写清楚

市场复审的第二条意见是：`README` / `playbooks/compose.md` 一边说「一句话变设计文档」，一边要求先补 `goals`/`data`/`boundaries`，是夸大。

这一版只改文档措辞，不改行为：

- 中文 README 首屏从「一句需求 → SPEC → 评审 → 任务卡 → 证据」改成「先写 plan（模型填内容），工具校验后出 SPEC → 独立评审 → 任务卡 → 实现证据」。
- 英文 README 新增 **What "one requirement" actually means**：一句话是循环的起点，循环里要填 plan、跑独立评审、按需回填实现证据；文档不再暗示这是一步完成的。
- 0.4.45 / 0.4.46 的暂存件请直接拒掉，只批 0.4.47：前两版的 tarball 与仓库不一致（0.4.45 带旧 README 措辞，0.4.46 只修了门禁里的 TODO 字样）。
