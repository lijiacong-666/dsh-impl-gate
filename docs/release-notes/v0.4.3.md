# 0.4.3

把 warnings 从 README 里的一大段散文，拆成一份可查的表：`docs/WARNINGS.md`。

## 变更

- 新增 `docs/WARNINGS.md`：29 类 warnings 按「A 契约没闭合 / B 决定没做 / C 可能误报」三组，每类写清触发条件与消法，末尾给一份典型的收敛顺序（先 A，再 B，C 留着要写理由）。
- README 的 warnings 段从长段落改成一句摘要 + 链接。
- `package.json` 的 `files` 本来就包含 `docs`，所以这份表会随 npm 包一起发布。

## 升级注意

没有行为变化；只是文档结构变了。如果你的 CI 在解析 README 里的 warnings 列表，改读 `docs/WARNINGS.md`。
