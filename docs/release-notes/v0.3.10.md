# 0.3.10

## 修复

- **任务卡不再过期**：`tasks/` 里存在 `impl_gate_record` 写的 `EVIDENCE.md` 时，`impl_gate_init`（以及 materialize 的自动刷新）过去会以 `EXPORT_REFUSED — tasks/ already contains files this tool did not generate` 拒绝重建，导致改了 plan 之后卡片仍是旧验收命令。现在把 `tasks/EVIDENCE.md` 视为本工具自己的文件，重建时保留它、只重写卡片。
- **Node 版本要求放宽**：`engines.node` 从 `^22.19.0 || >=24.0.0` 改为 `>=22.14.0`。原来的下限比 DSH 宿主自带运行时还高，在 22.14 上会一直报 `Unsupported engine`。

## 升级注意

- 若你之前手工改过 `tasks/` 下的卡片，`overwrite: true` 仍会覆盖它们（除 `EVIDENCE.md`）；卡片应以 `compose-plan.json` 为准重新生成。

## 已知缺口

- 不变：结构可判、语义留白仍需评审或开工会上问（见 README 的 warnings 与 `docs/CASE-STUDY-mini.md`）。
