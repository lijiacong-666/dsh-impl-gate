# v0.4.46 — 发布门禁修复

上一版（0.4.45）把引擎打进包里，但 GitHub Release 流水线的 `gate` 步骤在 `node scripts/check-release.mjs` 处失败：

```
::error::README.en.md still has TODO sections; see playbooks/reference/readme.md.
```

原因不是内容缺失——英文 README 里描述 `mode:"plan"` 时写了 “rendered with explicit TODO slots”，门禁把任何 `TODO` 字样当作未完成章节。改成 “explicit unfilled slots” 后 `check-release.mjs` 通过。

## 改了什么

- `README.en.md`：一处措辞。
- 版本号 0.4.46（0.4.45 的 npm 暂存件内容与仓库不一致，按 `docs/RELEASE-QUEUE.md` 的「只批最新一版」处理：批 0.4.46，拒 0.4.45）。

## 验证

```
node scripts/check-release.mjs   # Release v0.4.46 verified (stable)
node scripts/build.mjs           # built dsh-impl-gate@0.4.46
```

功能与 0.4.45 完全一致（自带 specgraph 引擎、解析回落、测试与文档）。
