# 0.3.13

## 新增警告

- **`AC_TEST_UNRUNNABLE`**：验收命令的首词不在 `impl_gate_record` 的白名单里（`pnpm`/`npm`/`npx`/`node`/`python`/`git`/`cargo`/`go`/…），或者干脆没写命令。这类行在 record 时会变成一条 `SKIPPED — RUNNER_NOT_ALLOWED`，看起来「跑了」，其实没有任何证据。真实项目里出现过「AC 写 `pnpm test storage -- --grep 迁移幂等`，而仓库没有这个脚本」——直到实现者跑起来才暴露。

## 实测

- fitness / run-log / mini 三份真实 plan 都没有误报（它们的命令都以 `npx vitest run …` 或 `pnpm test` 开头）。
- 白名单与 `impl_gate_record` 执行时用同一份（`ALLOWED_RUNNERS` 从 record 模块导出），不会出现「警告说能跑、record 说不能跑」。

## 已知缺口

- 白名单按「首词」判断，`cmd /c npm test` 这类包装写法会被判为不可执行；需要时把 `cmd`/`powershell` 加进白名单即可，那是有意的收紧。
