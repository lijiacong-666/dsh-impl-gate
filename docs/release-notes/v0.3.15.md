# 0.3.15

## 改了什么

- `LIST_ORDER_UNDEFINED` 识别「升序 / 降序」写法（此前只认「排序」「order by」），并且会看
  **产出方模块**的约束，而不只看路由所属的壳模块：`M4.listExpiringReminders` 声明「按剩余天数升序」
  就能让 `/api/reminders` 不再报警。
- `BOUNDARY_UNUSED` 不再把环境类边界（本机数据目录、离线运行、单机部署、用户数据目录）当成
  「声明了却没接的外部依赖」。
- `HTTP_ROUTE_UNCOVERED` 跳过静态资源路由（`.js/.css/.html/图片/字体`）：它们的验收是
  「页面能加载」，不是逐条业务断言。
- 修正 `tests/playbook.test.mjs` 的章节清单——0.3.14 新增的「materialize 的 warnings 怎么读」一节
  此前让它失败（提交时漏跑 verify）。

## 效果

药箱盲测第二轮物化后，结构性警告从 8 条降到 **0 条**，只剩 `OPEN_QUESTIONS_PENDING (3)`
（三个真的是产品决策的未决项）。三条降噪都在真实 plan 上验证过，不是只改了单测。
