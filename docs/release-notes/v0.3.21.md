# 0.3.21

## 改动

- 新增警告 `PAGINATION_MODE_CONFLICT`：同一路由同时声明了偏移式分页（`page` / `pageSize` / `perPage` /
  `offset` / `limit`）与游标式分页（`cursor` / `after` / `before`）。这类文档必须由实现者自己发明优先级
  （两个参数都传时谁赢），而这类「发明」往往在联调时才暴露。
- 真实 plan 复核：pillbox / run-log / fitness 均无误报（fitness 的三条是 `LIST_PAGINATION_UNDECLARED`，
  属既有的公开缺口）。

## 升级注意

- 纯新增警告；`validatePlan` 仍不拦截。

## 已知缺口

- 只查「同时声明」，不查「声明了却没实现」——后者要靠 `impl_gate_record` 的验收命令。
- 药箱 `GET /api/reminders/home` 仍是 `LIST_PAGINATION_UNDECLARED`，等 M4 实现时一起补。
