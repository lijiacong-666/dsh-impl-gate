# 0.4.24 — 冒烟能在没有夹具的机器上安静跳过

## 改了什么

- `scripts/smoke.mjs` 加 `--ci`（`pnpm smoke:ci`）：环境不具备时（四份真实 plan 不在、Python/specgraph 不可用）逐条打印 `SKIP` 并退出 0，不再把「这台机器没有夹具」当成失败。
- 新增 `SMOKE_SNAPSHOT` 环境变量：可以指定另一份快照做对照，不必改动仓库里那份。
- 漂移仍然是失败：警告集合、卡数、`check` 计数任一对不上，退出码 1 并打印「实际 vs 期望」。

## 验证记录

正常跑：

```
mini      OK   warnings=7  cards=1  check=10 pass
fitness   OK   warnings=7  cards=8  check=10 pass
pillbox   OK   warnings=2  cards=9  check=10 pass
run-log   OK   warnings=6  cards=7  check=10 pass
smoke ok
```

故意把快照里 mini 的警告集合加一个 `BOGUS_CODE`：

```
smoke failed (1):
- mini: snapshot drift — warnings [...7 个...] vs [...8 个...]; cards 1 vs 1; check 10/0 vs 10/0
exit 1
```

## 注意

- `--ci` 只降低「环境缺失」的严格度，不降低「输出变化」的严格度。
- `SMOKE_SNAPSHOT` 便于验证「改了警告逻辑但还没更新快照」时的具体差异，避免直接 `--update` 掩盖问题。
