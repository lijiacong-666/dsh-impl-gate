# v0.3.8

## 改动

- `AC_SHELL_LATER` 降噪：只报「AC 调用了别的模块拥有的路由」。模块自己声明了那条路由时，测试可以自己 `new Fastify()` + `inject`，不必等 shell 波次——真实项目（run-log）里 9 条误报因此归零。
- 新增 `TOOLING_UNOWNED`：有验收命令、但没有任何模块拥有 `package.json`（或 `pyproject.toml`/`go.mod`/`Cargo.toml`/`pom.xml`/`build.gradle`）时给出警告。第一个实现者否则只能自己发明工具链，和契约对不上。

## 升级注意

- 无接口变化；warnings 从 18 类变 19 类。

## 已知缺口

- 同 0.3.6。
