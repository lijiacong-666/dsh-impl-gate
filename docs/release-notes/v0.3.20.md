# 0.3.20

## 改动

- 新增警告 `LIST_PAGINATION_UNDECLARED`：响应的类型带 `total` / `totalCount` / `hasMore` / `nextCursor` / `pageSize`
  这类分页簿记字段，但该路由没有声明 `page` / `pageSize` / `limit` / `offset` / `cursor` 查询参数。
  这类缺口在做药箱 M2 时被实现者提了出来：文档给了 `total`，却没给分页参数，`total` 只能等于「查到的全部行数」。
- 真实 plan 复核：pillbox 触发 2 条（`GET /api/medicines`、`GET /api/reminders`），run-log 与 fitness 无误报。
- README 的 warnings 段更新到 24 类。

## 升级注意

- 纯新增警告，不改变已有 plan 的校验结果（`validatePlan` 仍不拦截）。
