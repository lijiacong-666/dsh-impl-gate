# 0.3.16

## 改了什么

- 新增警告 `CONSTRAINT_FIELD_UNKNOWN`：散文里写 `ReminderQuery.medicineId`、但 §4.2 的类型字段表里
  没有这个字段时报警。来自药箱盲测第五轮——第四轮的修复只改了约束与 HTTP 参数，漏了类型，评审照旧不可开工。
- 外部类型（`kind: "external"`，例如 Fastify 的 `HttpApp`）不再打印「由该模块的某个文件定义并导出」，
  改为 `维护：M8（外部类型，只在此登记来源，不要求本模块定义）`。

## 效果

药箱需求第 6 轮评审 **9/9 可开工、blocking = 0**，通过了；`CONSTRAINT_FIELD_UNKNOWN` 已在
修复前的 plan 上验证会触发，修复后消失。

## 已知缺口

- 类型字段与散文的一致性只检查 `Type.field` 这种显式写法；「字段在别的句子被换个名字提到」查不出来。
- external 类型的 `source` 目前只是文本，不做版本核验。
